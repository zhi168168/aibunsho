## DeepSeek 真实联调更新

用户添加本机密钥后，修复了 Vite 通过修改 process.env 导致旧值覆盖新 .env 的问题：现在开发和预览请求直接使用当前 loadEnv 配置，不污染进程环境。服务端部署仍读取平台环境变量。

已经通过生产预览页执行 **1 次真实 DeepSeek 调用**，使用站点内 318 字的公开日语样例，模型为 `deepseek-flash`，返回 18/100 主观文体参考分、日语分析说明及 4 条原文观察。结果在页面正确展示，报告下载后内容核验通过。此样例不能证明检测准确率。Copyleaks 仍未真实调用。

当前配置状态为 configured:true，密钥只在本机 .env 和服务端使用，未写入页面或记录。真实结果截图见 `screenshots/deepseek-live.jpg`。

## 视觉与响应式

使用内置浏览器 IAB 的截图和真实操作，未使用 Playwright Chromium 回退。对参考截图及最终实现截图均调用 `view_image` 人工核对。桌面按参考截图的 1265 × 712 尺寸检查；手机检查 390 × 844 和 320 × 740，并恢复默认视口。

| 对照项 | 参考及实现证据 | 调整结果 |
| --- | --- | --- |
| 背景与配色 | 参考为近黑底、浅色文字、细暗边框、少量紫色；实现使用 #0b0b0d 底和 #c6b5fa 点缀 | 保留暗色风格，没有添加无关照片或大面积渐变 |
| 顶部导航 | 参考是有细边框的胶囊导航 | 使用同类胶囊导航，日语菜单与工具锚点 |
| 标题与留白 | 参考是居中粗体主标题，节制的说明文字 | 日语标题、集中式层级与宽留白；缩减首屏过大的上方间距 |
| 工具容器 | 参考是圆角、有工具栏的产品预览 | 转换为实际双栏输入/结果工具，细边框和紫色状态保持一致 |
| 辅助文字 | 初版部分分析说明太小 | 已放大桌面编辑区与说明字号，检查日语换行 |
| 手机交互 | 双栏在小屏不适用 | 单列布局，主按钮位于输入区之后，结果在下方；320px 无横向滚动 |
| 下方内容 | 保留同一套背景、边框、字体层级 | 开放式三步骤、左右分栏分析介绍、FAQ、结尾行动按钮，避免反复卡片堆叠 |
| 图标与图形 | 细线工具图标 | 统一 lucide 风格，扫描空状态和示意节奏条为代码原生图形，操作文字不是图片 |

首屏文字核对：单一 H1 包含「AIチェッカー」；导航、说明、三个特性文字和 CTA 与最终源码及预渲染 DOM 一致。DeepSeek 接入后，有意新增分析引擎切换，将“全部不上传”改为仅本地分析不上传，避免隐私表述与功能冲突。

实现遵循参考站的视觉方向完成对照验证；这是新产品的信息架构，**不是逐像素复制原站**。有意差异包括日语字体、真实检测工作区、紫色主按钮和引擎切换。没有尚未修复的已知裁切、溢出或损坏操作。没有图片生成稿可供匹配。

## 功能与工程

- `pnpm build`：通过 TypeScript、Vite 生产构建、静态首页预渲染。
- `pnpm test`：11 项测试通过，覆盖 Unicode 字符、短文/超限、实际统计、不可用指标、报告说明、DeepSeek JSON 解析与原文引用校验、截断和格式错误、认证/余额/限流错误、无自动付费重试、Copyleaks 令牌复用和 Sandbox 标记。
- IAB：两种样例、实际分析、逐句切换、清空、TXT 文件导入后继续分析、短文和超限按钮禁用、报告下载、复制成功反馈、手机菜单、FAQ、隐私弹窗。
- 下载的 TXT 报告已经读取验证，包含方法版本、计算结果和非概率说明。
- 未配置模型时：`GET /api/detect` 返回 200 和 `configured:false`；POST 返回 503，前端显示准备中，不伪造模型结果。
- 修复开发页 HTML 注释引起的 hydration 错误；最终生产页浏览器控制台错误为空。
- 生产 HTML 包含完整日语正文、单一 H1、FAQPage 结构化数据，不包含密钥变量。正式域名未定，未添加虚假的 canonical 或域名。
- 首轮未配置密钥时只做了模拟响应测试；后续 DeepSeek 真实联调已完成，见本页更新。Copyleaks 推理和检测有效性评估仍未执行。

## 检查过程动画更新

新增 SVG/CSS 机器人扫描文章动画：轻微浮动、放大镜移动、文档扫描光带，配合日语读取/分析/结果整理三步提示。状态由实际请求流程驱动，不显示虚构百分比；API 等待期间停在分析步骤，错误后退出。快速本地分析的状态至少显示约 1.1 秒，避免闪烁。支持 prefers-reduced-motion。

生产构建和 14 项现有测试通过。浏览器验证：本地样例出现动画后正常显示结果；处理中清空输入恢复输入等待，不出现旧结果；390px 手机端动画可见且无横向溢出。此次验证未调用付费 API。截图：`screenshots/analysis-loading.jpg`、`screenshots/analysis-loading-mobile.jpg`。
