# 高级报告功能与验证

日期：2026-11-05。当前开放使用，不包含支付、付费解锁、账户历史或批量处理。

## 用户流程

输入100～10,000字后，点击工具下方「詳細レポートを作成」。无需先跑普通模型检测。全文通过现有服务端发送到 DeepSeek，生成一次独立报告，消耗一次现有模型配额；不自动重试。已经生成的报告可以反复打开，关闭和重新打开不会发起请求。报告只保存在当前页面内存，改写输入、切换模式或刷新会清除。

报告包含总评、优点、优先检查事项、8项本地统计、区分原文、有效引用、分析解释、改善建议、可选的引用部分改写示例、局限说明、全文原文和报告ID。改写示例不会应用到输入。

空行划分段落，超过800字符的段落分割；区分过多时按顺序合并，最多16区分。所有区分保留原文中的连续内容，支持 Unicode。模型需为每个区分返回对应ID及精确引用。缺失、重复ID、错误引用或字段错误会使该区分标为未取得，显示有效覆盖数；全部无效则报错，不显示完整报告假象。

## 导出

- TXT保存：包含全部原文、解释、建议和注意事项。
- 印刷 / PDF保存：调用浏览器打印，选择「PDFに保存」。A4打印样式隐藏网站和操作栏，显示完整报告，不截取滚动视窗。
- PDF不是服务器生成的自动下载文件。浏览器的打印选择由用户完成。

## 实现边界

报告生成仍是 DeepSeek 的编辑辅助，原文引用一致不意味着解释正确。改写可能改变含义，使用前须核对；没有外部来源检索、事实验证或抄袭比对。既有模型限额共用，长报告消耗的 token 通常多于普通摘要，实际价格按服务商计费。50秒上游超时，沿用Vercel函数60秒配置；耗时不是SLA，失败不会自动重试，失败请求仍可能消耗本站配额或服务商额度。没有增加数据库存储或新服务商。
