# 免费结果精简与详细报告易读性

- 用户要求免费版只保留总分和维度，不展示六条引用依据，不提供本地统计。
- 移除首页本地统计入口及结果；免费模式直接调用现有模型服务，维持额度、内容确认与服务故障处理。免费 UI、复制和TXT输出仅提供总分、四维分数/解释及简短含义说明。
- 服务端仍使用精确原文证据校验模型结果与高分条件；内部引用不展示在免费结果中，未降低证据校验。
- 高级报告去掉统计指标和区分编号，以全评、优先考虑、原句、为什么、怎么处理呈现。保留评价、原文全文与长说明折叠，按需展开；打印时展开并在打印后恢复。
- 高级提示词要求日常语言，避免抽象编辑术语；不强制制造问题或改写。优先项由已核验且需修改/确认的句子直接构建，避免概览要求修改、正文却建议保留的矛盾。
- 同步首页、套餐、FAQ、指南和隐私说明，明确免费模式也会向模型提供方和内容检查服务发送文本。不再承诺浏览器内分析或免费无限次。
- 44项测试及生产构建通过；本地浏览器以实际《春》结果确认免费总分/四维、详细报告重点内容与保留内容展开。以新提示词真实生成9/9有效评价，7项保留、2项可选确认，无强制改写。中文示例仅在忽略的work目录，不将用户全文提交Git。
