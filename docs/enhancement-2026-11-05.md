# DeepSeek + 日本語ルールの強化（2026-11-05）

既存の DeepSeek API を使い続け、専用 API や GPU サービスを追加せずに、観測指標・根拠の検証・不確実な結果の扱いを改善しました。専用検出器への変更や検出精度の保証ではありません。

## 実装

- 本地分析を4指標から8指標へ拡張：句長、定型句、文末、フレーズ反復に加え、文頭の反復、80文字窓の文字 bigram 多様性、空行区切りの段落長、隣接文の類似性を計測。
- 普通の接続詞だけでは定型句スコアを加算せず、文末一致の重みも軽減。重みは手動設定であり、学習・校正済みではありません。bigram は形態素解析ではありません。
- 学術・契約、箇条書き、コード、引用・会話、日本語割合について注意点を表示。
- DeepSeek はジャンルを考慮し、構成・表現・具体性・一貫性の4項目をレビュー。観測値を送りますが、本地総合スコアは渡しません。
- 原文と一致する引用だけを採用し、重複・範囲が重なる引用を除外。定型性の根拠、別の解釈、曖昧な特徴を分けて表示。
- 短文、材料不足、不十分な引用、高評価と反証の衝突等では総合値を null にし、「— / 保留」を表示。0点への置換や本地値との平均はしません。
- 1回のチェックにつきモデル呼び出しは1回。自動有料リトライなし。ただし指示・回答の増加で従来よりトークン料金が増える可能性があります。

## 検証

生データは `enhancement-evaluation.json`。旧バージョンは `c144512`、新ルールは `japanese-style-2.0` です。

| 工程用サンプル | 旧本地スコア | 新本地スコア |
| --- | ---: | ---: |
| 一般的接続詞を含む通知 | 47 | 9 |
| 定型的な正式文 | 71 | 48 |
| 同内容の繰り返し | 75 | 79 |
| サイトの概説サンプル | 58 | 30 |
| サイトの個人的叙述サンプル | 16 | 7 |
| 日本語以外の文章 | 50 | 41（評価材料不足） |

これら6件は作成した工程テストで、人間／AIの正解ラベルを持つ評価データではありません。スコア低下自体は精度向上の証拠ではありません。

さらに青空文庫の夏目漱石『吾輩は猫である』（1905年刊行開始）の684文字を追加。歴史的な人間の文章ですが、モデルが作品を記憶している可能性があり、現代日本語の代表的な盲検サンプルではありません。

保存済みの実 API 結果は3件：概説サンプル62、個人的叙述22、歴史的文章は判断保留。いずれも有効な原文引用と4項目を返しました。さらに現在の本番ビルドのブラウザから概説サンプルを1回実行し、58・混在評価、分項展開と根拠表示を確認しました。同一文章でも結果は変動し得ます。

22件の自動テストと本番ビルドが通過。偽引用・重複・重なる引用、値域、項目欠落、根拠不足、短文、接続詞、非日本語、API呼び出し回数を含みます。デスクトップ1280px、モバイル390pxで表示確認し、モバイルの横幅と scrollWidth が一致しました。

## 再実行と限界

`pnpm exec tsx scripts/evaluate-review.ts` は本地比較のみです。`--live` を付けると有料 API を呼び出すため、意図して指定してください。評価ファイルは上書きされます。

大規模な正解付きデータ、誤検知率・見逃し率、確率校正は未検証です。高い評価と反証が衝突した際の保留は誤断定を減らすための設計ですが、検出漏れも増やし得ます。引用の一致を確認しても、説明の妥当性・方向付けまでは保証できません。モデルやルールだけで執筆者を確定できず、文章の出典・下書き・改訂履歴との確認が必要です。
